# Period-Tracker
A feminine and user-friendly period tracker designed to help users monitor their menstrual cycle, predict upcoming periods, and understand their body better. This app provides cycle tracking, symptom logging, and helpful reminders to support daily health and well-being.

🌸 Main Features
Cycle Calendar
→ Mark period days, ovulation, and predict the next cycle
Automatic Prediction
→ Estimate upcoming periods and fertile window
Symptom Log
→ Track cramps, mood changes, acne, and more
Daily Notes
→ Users can write their daily condition or experiences

🧠 Educational Features
Information about the menstrual cycle
Explanation of PMS, ovulation, etc.
Health tips (nutrition, light exercise, etc.)
Simple FAQ for easy understanding (student-friendly)

🔔 Reminders
Notifications before the next period
Medication / vitamin reminders
Health check reminders

💖 Personalization
Custom colors/themes (feminine style 🌷)
User name / avatar
Choose app vibe (cute, elegant, minimal)

📊 Tracking & Insights
Cycle statistics (regular / irregular)
Mood and symptom charts
Previous cycle history

🔒 Privacy
App lock (PIN / fingerprint)
Secure and private data

✨ Bonus Features
Daily motivational / self-love quotes
Mood tracker with emojis
Mini diary / journaling
Light AI tips (e.g., “Feeling PMS? Try to get some rest 💛”)
